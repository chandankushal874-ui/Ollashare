Shared Browser

A cloud browser that belongs to the room.

The host provisions a clean remote browser. Eligible room participants can view it, while controller access is granted deliberately and can be revoked.

View-only by default

Participants see the same browser without receiving keyboard or pointer input.

Host-granted control

Short-lived grants bind access to the participant, room, session and mode.

Controlled browser egress

Browser traffic is restricted to public HTTP and HTTPS destinations.

Room lifecycle revocation

Ending the room invalidates browser sessions, grants and controller permissions.

FAQ

Practical questions, answered plainly.

Do guests install anything?

No. Guests use the room link without an extension or separate account.

Can Ollashare control a desktop?

No. Local assistance is restricted to the authorized Ollashare browser tab.

What is the Shared Browser?

A remote browser tied to the room. The host grants controller access when needed.

Can several people control it?

Multiple controller leases are supported, so teams should coordinate who is typing or pointing.

How large can a room be?

Hosts can configure viewer and simultaneous sharing limits.

What happens when the host leaves?

Room teardown invalidates related browser grants and collaboration state.
